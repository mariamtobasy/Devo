# Devo

Devo is a web-based productivity and task management system designed to help individuals and teams organize their work, track progress, and collaborate efficiently in one centralized platform.

This project was developed as a graduation project and focuses on building a complete, real-world full-stack web application using modern frontend and backend technologies.

---

## ✨ Features

### 🔐 Account & Security
- User authentication and authorization using JWT (JSON Web Tokens)
- Change password functionality
- Update email address
- Cookie management and cookie consent handling
- Secure session handling

### 📋 Task & Workflow Management
- Kanban-style task boards:
  - To Do
  - In Progress
  - In Review
  - Done
- Task priority levels (e.g. urgent, medium)
- Task tags and detailed descriptions
- Assign tasks to users
- Assigned users can view tasks when logged into their account

### 👥 Teams & Collaboration
- Team-based task organization
- Task assignment between users
- Shared visibility of assigned tasks

### 🧠 Productivity Features
- Focus Timer (Pomodoro-style)
- Personalized dashboard
- Notes management
- Calendar view
- Global search across tasks, notes, and meetings

### 🔔 Notifications & Support
- Notification system for task updates and assignments
- Help articles and support content
- Contact Us feature for user communication

### 🎨 Customization & Accessibility
- Light and Dark themes
- Arabic language support (full UI localization)
- Clean and user-friendly interface
